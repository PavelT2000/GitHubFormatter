# Kursach

> A Delphi-based desktop application for parsing, evaluating, and visualizing mathematical expressions. Developed as an academic coursework project following BSUIR standards.

## 📖 Overview
**Kursach** is a Windows desktop application built with Embarcadero Delphi and the VCL framework. It provides a custom mathematical expression parser, a real-time evaluation engine, and graphical rendering capabilities for mathematical functions and fields. The repository includes comprehensive academic documentation, algorithm flowcharts, and LaTeX templates compliant with Belarusian State University of Informatics and Radioelectronics (BSUIR) formatting guidelines.

## ✨ Features
- **Custom Expression Parser** (`MyParser.pas`): Lexical analysis and syntactic parsing of mathematical expressions with support for operators, parentheses, and variables.
- **Evaluation Engine** (`Expression.pas`): Computes parsed expressions with proper operator precedence and runtime error handling.
- **Graphical Visualization** (`Drawer.pas`, `Field.pas`, `ScrollBox.pas`): Renders mathematical fields/functions with interactive scrolling, scaling, and coordinate mapping.
- **VCL-Based GUI** (`Main.pas`, `Main.dfm`): Native Windows interface for expression input, parameter configuration, and real-time visualization.
- **Academic Documentation**: Complete explanatory notes (`ПЗ`), technical specifications, and algorithm flowcharts (`FlowCharts/`).

## 🚀 Getting Started

### Prerequisites
- Embarcadero RAD Studio (Delphi) 10.3 or later
- Windows OS (VCL is Windows-only)

### Build & Run
1. Open the main project in RAD Studio:
   ```bash
   # Open via IDE
   File → Open → App\Kursach.dproj
   ```
2. Verify that all units (`Main.pas`, `Expression.pas`, `Field.pas`, `ScrollBox.pas`, `MyParser.pas`) are included in the project's search path.
3. Compile (`Ctrl+F9`) and run (`F9`).

### Testing
The `EvalTest/` directory contains a standalone test harness for validating the parser logic. Open `EvalTest\Test.dproj` to run isolated evaluation tests against `MyParser.pas`.

## ⚙️ Development Notes
- **IDE Artifacts**: Directories like `__history/`, `BackUp/`, and files with `.dproj.local`, `.identcache`, or `.vlb` extensions are auto-generated by Delphi. They are excluded from version control via `.aiignore` and `.gitignore`.
- **Backup Strategy**: Historical parser iterations are preserved in `App/BackUp/MyParser.pas` and `EvalTest/BackUp/MyParser.pas` for academic reference.
- **Language**: Source code and comments are primarily in English/Russian. Academic documentation is in Russian per university requirements.
