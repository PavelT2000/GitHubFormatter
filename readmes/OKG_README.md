# OKG

> **Project Type:** CAD/Engineering Laboratory Assignments  
> **Primary Software:** Autodesk Inventor / AutoCAD  
> **Language:** Russian (File Naming) / English (Documentation)

## 📖 Overview
The **OKG** repository serves as a centralized, version-controlled workspace for engineering laboratory assignments. It contains 3D part models (`.ipt`), 2D technical drawings (`.dwg`), exported documentation (`.pdf`, `.png`, `.bmp`), and design assets. The project is structured to support iterative design, manual version tracking, and AI-assisted workflows.

## 📁 Repository Structure
```text
OKG/
├── ЛабораторнаяРабота№1/          # Primary lab assignment workspace
│   ├── OldVersions/               # Archived iterations & manual backups
│   ├── *.ipt                      # Autodesk Inventor part files
│   ├── *.dwg                      # 2D technical drawings
│   ├── *.pdf                      # Exported documentation
│   └── *.png, *.bmp, *.psd        # Visual assets & renders
├── лабы для санька/               # Secondary lab assignment folder
├── .aiignore                      # AI context exclusion rules
└── .gitattributes                 # Git line-ending & text normalization
```

## 🛠️ Prerequisites & Software
To open, edit, and export files in this repository, ensure the following software is installed:
- **Autodesk Inventor** (Recommended for `.ipt` and `.dwg` compatibility)
- **AutoCAD** or **DWG TrueView** (For 2D drawing review)
- **PDF Viewer** (For exported documentation)
- **Image Editor** (Optional: Photoshop/GIMP for `.psd`, `.png`, `.bmp` assets)

> 💡 **Version Compatibility:** CAD files are sensitive to software versions. Always open files in the same or newer version of the originating software to prevent data corruption or feature loss.

## 🔄 Workflow & Best Practices
1. **Working Directory:** Perform all edits in the root lab folders (`ЛабораторнаяРабота№1/`, `лабы для санька/`).
2. **Versioning:** Before major modifications, copy the current state to `OldVersions/` with a descriptive, timestamped name.
3. **Exports:** Generate `.pdf` and image exports directly from Inventor/AutoCAD to maintain scale, layers, and dimension integrity.
4. **Temporary Files:** Ignore `~*.tmp` and lock files. These are auto-generated by CAD software during active sessions and should never be committed.
5. **AI Context Management:** This repository uses `.aiignore` to prevent large binary CAD files from consuming AI assistant context windows. AI tools will only process configuration and text-based files.

## ⚙️ Configuration Files

### `.aiignore`
Excludes CAD binaries, temporary files, OS artifacts, and backup directories from AI context parsing. This ensures faster response times and prevents token limit exhaustion when using AI coding/design assistants (e.g., Cursor, GitHub Copilot, Claude Code).

### `.gitattributes`
```gitattributes
* text=auto
```
Enforces automatic line-ending normalization (LF/CRLF) across operating systems. Ensures consistent repository behavior for cross-platform collaboration and prevents false diff noise.

## 📦 Large File Handling (Recommendation)
CAD files (`.ipt`, `.dwg`, `.pdf`, images) are binary and can grow rapidly. For long-term scalability and faster clone/pull operations, consider migrating to **Git LFS**:
```bash
git lfs install
git lfs track "*.ipt" "*.dwg" "*.pdf" "*.png" "*.bmp" "*.psd"
git add .gitattributes
git commit -m "chore: configure Git LFS for CAD binaries"
```

## 📝 Notes
- File names follow Russian academic conventions. Maintain original naming to preserve reference integrity and grading alignment.
- Do not manually edit `.dwg` or `.ipt` files outside of supported CAD software.
- The `OldVersions/` directory is excluded from AI context but tracked by Git. Use it for manual rollback only.
- Clean up `~*.tmp` files before committing to keep the repository tidy.
