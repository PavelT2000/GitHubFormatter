Легковесное self-hosted веб-приложение на **FastAPI** и **Jinja2**, оптимизированное для работы на одноплатных компьютерах (Orange Pi Zero 3). Проект выполняет роль персонального дашборда, базы знаний по архитектуре сервера и справочника Linux-команд.

Архитектура включает автоматизированный CI/CD пайплайн через GitHub Actions с развертыванием по SSH и управлением через `systemd`. Безопасный удаленный доступ реализован с помощью **Tailscale** (mesh-сеть) и **Cloudflare Tunnel**, что исключает необходимость открытия портов на роутере.
