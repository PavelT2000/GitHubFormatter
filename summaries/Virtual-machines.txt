**Virtual-machines** — это инструмент для автоматизации жизненного цикла виртуальных машин, реализующий принципы Infrastructure-as-Code (IaC). Проект предоставляет унифицированный CLI-интерфейс для развертывания и управления ВМ, абстрагируя различия между гипервизорами (QEMU/KVM, VirtualBox, VMware) и облачными провайдерами (AWS, Azure).

Архитектура ориентирована на воспроизводимость сред и интеграцию в CI/CD-пайплайны. Система поддерживает декларативное описание конфигураций, автоматизированную настройку ресурсов и кроссплатформенную нормализацию окружения через `.gitattributes`. Проект оптимизирован для совместной разработки: включает правила `.aiignore` для исключения артефактов из контекста LLM и модульную структуру для расширения поддержки новых провайдеров.
