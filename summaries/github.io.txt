Адаптивный сайт-портфолио на базе шаблона Start Bootstrap Resume, предназначенный для демонстрации профессионального опыта и навыков. Проект представляет собой легковесное статическое приложение, оптимизированное для быстрого развертывания на GitHub Pages.

**Технологический стек:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5.2.3, Font Awesome 6.3.0.

**Ключевые особенности и архитектура:**
*   **UI/UX:** Адаптивная верстка, фиксированная боковая панель с навигацией (ScrollSpy) и плавная прокрутка.
*   **Контент:** Модульная структура разделов (опыт, образование, навыки), визуализация стека технологий через иконки.
*   **Производительность:** Минималистичная архитектура без серверной части, использование CDN для внешних зависимостей.
