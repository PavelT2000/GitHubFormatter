Проект представляет собой десктопное игровое приложение, разработанное в рамках лабораторной работы БГУИР (2024). Для запуска требуется исполняемый файл из директории `release game`.

Технический стек и архитектура основаны на стандартной сборке для Windows-приложений. Проект реализован как автономное решение, не требующее установки дополнительных зависимостей, с инкапсуляцией всех игровых ресурсов и логики в рамках единого исполняемого модуля.
