ASP.NET Core Web API (.NET 8/9) для управления складским учетом. Архитектура построена на разделении ответственности (Controller → Service → Repository/DbContext) с использованием Entity Framework Core и MS SQL Server. API предоставляет REST-эндпоинты для фильтрации товаров и складов по бизнес-правилам, включая расчет стоимости инвентаря и выборку по датам/статусам.

Проект поддерживает автоматическую генерацию документации через Swagger/OpenAPI. При запуске реализована автоматическая пересборка БД с сидингом данных. Бизнес-логика изолирована в слое сервисов, а доступ к данным осуществляется через асинхронные LINQ-запросы.
