**LANChatQt** — легковесное кроссплатформенное приложение для обмена сообщениями в локальной сети (LAN) без использования выделенного сервера. Стек: **C++17**, **Qt 5.15+/6.x**, система сборки **qmake**.

**Основные возможности:**
*   **Zero-Config:** автоматическое обнаружение узлов через UDP-широковещание.
*   **Надежность:** доставка сообщений через P2P TCP-соединения.
*   **Мониторинг:** отслеживание статуса участников через механизм Heartbeat (таймаут 15с).

**Архитектура:**
Приложение разделено на четыре модуля: `MainWindow` (UI), `ChatEngine` (бизнес-логика, управление состоянием узлов), `NetworkManager` (абстракция сокетов UDP/TCP) и `Packet` (сериализация данных через `QDataStream`). Взаимодействие строится на UDP для обнаружения и TCP для передачи данных, что обеспечивает баланс между скоростью поиска и гарантированной доставкой сообщений.
