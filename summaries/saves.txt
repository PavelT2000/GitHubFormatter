**Saves** — легковесная Windows-утилита для версионирования игровых сохранений (ZIP-архивов) через Git. Инструмент автоматизирует цикл синхронизации локальных данных с удаленным репозиторием с помощью пакетных скриптов.

**Технический стек и архитектура:**
*   **Среда:** Windows 10+, Git (CLI).
*   **Автоматизация:** `AutoGit.bat` (автоматический `add`, `commit` с фиксированным сообщением и `push`) и `GitFetch.bat` (`pull`).
*   **Структура:** Использование именованных ZIP-архивов для разделения ручных и автоматических сохранений.
*   **Особенности:** Поддержка кэширования учетных данных Git для бесшовного выполнения скриптов. При работе с большими объемами данных рекомендуется интеграция Git LFS.
