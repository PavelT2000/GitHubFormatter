**MyAiBotTg** — асинхронный Telegram-бот на базе `aiogram 3.x` и OpenAI Assistants API (v2), предназначенный для обработки предметно-ориентированных документов и ведения персистентных диалогов. Система автоматически индексирует документы (RAG) через OpenAI Vector Store, обеспечивая контекстно-зависимые ответы.

**Технологический стек:** Python 3.12, PostgreSQL (SQLAlchemy 2.0), Redis (FSM), Amplitude (аналитика). Архитектура включает контейнеризацию через Docker Compose, миграции базы данных через Alembic и модульную структуру сервисов для интеграции с LLM. Бот поддерживает автоматическое развертывание инфраструктуры, управление состоянием пользователей и версионирование схемы данных.
