Репозиторий содержит структурированный учебный путь по освоению .NET 8 и C# 12. Проект охватывает фундаментальные аспекты языка (ООП, асинхронность, коллекции) и разработку RESTful API на ASP.NET Core.

**Стек:** C# 12, .NET 8, ASP.NET Core Web API, Entity Framework Core 8, SQLite, JWT.

**Архитектурные решения:**
*   **API:** Реализован паттерн DTO для разделения доменных сущностей и моделей запросов.
*   **Безопасность:** Аутентификация через JWT с использованием middleware ASP.NET Core.
*   **Данные:** Code-first подход с миграциями EF Core и связями One-to-Many.
*   **Документация:** Интеграция Swagger/OpenAPI для тестирования эндпоинтов.
