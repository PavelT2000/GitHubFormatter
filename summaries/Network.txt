Коллекция примеров сетевого программирования под Windows на C++17 с использованием API WinSock2. Проект включает реализацию UDP-чата с широковещательной рассылкой и синхронную TCP-архитектуру (клиент-сервер).

**Технические особенности:**
*   **OnlineChat (UDP):** Использует `SO_BROADCAST` для передачи сообщений в локальной сети и многопоточность (`std::thread`) для асинхронного прослушивания входящих пакетов. Консольный интерфейс реализован через ANSI-последовательности.
*   **Test Work (TCP):** Реализует классический цикл `socket-bind-listen-accept-recv`. Сервер работает в блокирующем режиме, поддерживая одно клиентское соединение.
*   **Стек:** C++17, WinSock2 (`ws2_32.lib`), CMake. Проект предназначен исключительно для Windows.
